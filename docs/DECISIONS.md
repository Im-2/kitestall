- 2026-11-14 D1: pnpm workspace per spec §5. Node 24 locally; engines >=20.
- 2026-11-14 D2: Prompt Guard / Shadow Agent via `serv_*` marker tools (not model suffixes); Multipath via `-serv-multipath` suffix; Kronos off for JSON paths pending test. Reason: verified in docs.openserv.ai/serv-reasoning/tools.md.
- 2026-11-14 D3: Testnet asset PYUSD (18 decimals) at 0x8E04…2ec9 replaces spec's "Test USDT"; chain 2368; explorer testnet.kitescan.ai. Reason: current Kite docs.
- 2026-11-14 D4: Facilitator = Pieverse (https://facilitator.pieverse.io). Reason: Kite docs recommend it; confirmed live.
- 2026-11-14 D5: Internal 1 token == $1 assumption kept; 1 cent = 10^16 wei.
- 2026-11-14 D6: Prompt Guard block detection = finish_reason content_filter OR null content OR zero usage (see DISCOVERY). Treat ambiguous as blocked (fail closed).
- 2026-11-14 D7: SQLite via built-in `node:sqlite` (Node >=22.13) instead of better-sqlite3: no native build on Windows/Render. Dockerfile must use Node 24.
- 2026-11-14 D8: Plain CSS instead of Tailwind for the web app (custom ledger look, faster).
- 2026-11-14 D9: Self-relay settlement fallback when Pieverse settle fails (see DISCOVERY). Labeled everywhere.
- 2026-11-14 D10: Seed floors/salts: repo seed values are demo defaults and public; deployments get a random salt and may override floors via FLOOR_PCT_<SHOP>. README states the Arena tests the model/API path, not secrecy of the open-source defaults.
- 2026-11-14 D11: A Prompt Guard block does not consume a negotiation round (false positives were ~10-15%); abuse is bounded by rate limits and hourly session caps.
- 2026-11-14 D12 (UI redesign): animation library = **GSAP + ScrollTrigger with Lenis** (not Framer Motion). Reason: the design needs scroll-scrubbed parallax, horizontally sliding headline, pinned/stacked card reveals and number count-ups tied to scroll position; ScrollTrigger does this declaratively without re-rendering React, and Lenis supplies the inertial scroll that ScrollTrigger syncs with. GSAP is free to use; bundle cost ~70 kB gzip is acceptable (landing chunk is lazy-loaded, other routes only load Lenis).
- 2026-11-14 D13: new read-only `GET /api/public/activity` (redacted recent sales, rounds, fee totals, small real series) so the landing mockups can render the real dashboard without exposing owner-token endpoints. No existing endpoint or response changed.
- 2026-11-14 D14: web app is now light-theme only (matches reference); `prefers-color-scheme: dark` styles removed.
- 2026-11-14 D15: Render FREE plan, no disk. SQLite in /tmp; boot = seed + importHistory(docs/history.json) + assertSeeded. Signing keys come from SHOP_SIGNING_KEYS (env wins) so receipts verify across deploys. Historic policies are imported inactive (public part + hash only, no private part); the live policy takes the next version number. autoDeploy is off to save free build minutes.
- 2026-11-14 D16: history.json includes a 4th real settled sale (nomad/day-pass $22.50, tx verified on-chain) made through the web UI demo shopper; it is not in E2E_LOG.md (that log only records scripts/e2e-kite.ts runs). History is exported by script, not hand-written.
- 2026-11-14 D17 (SERV hard budget, $2 topped up, no more): OpenServ exposes no balance endpoint for API keys (/v1/balance, /credits, /usage, /billing all 404), so spend is ESTIMATED = token usage x catalog price x 3 (covers unmetered guard/multipath calls); guard-blocked calls (zero usage) are charged a flat $0.0008. Caps: $0.50/day and $1.70 total (slack for estimate error). Persisted in SQLite (`serv_spend`); a cold start with an empty counter assumes $0.15 already spent (never zero). Over a cap: SERV is not called, rounds are decided by the labeled deterministic fallback, UI banner + `budget_capped` flag. Abuse caps: 8 calls/session (guard blocks included), 30 calls/IP/day, 8 sessions/hour/item/IP, 25 SERV calls/min globally (burst degrades to labeled fallback), 8 demo-shopper runs/day, 429 on IP/session caps. IP = LAST x-forwarded-for entry. Prompt Guard always on; Shadow Agent off (SERV_SHADOW=0). Scripts that call live SERV (smoke-serv, bench, adversarial) refuse to run without --allow-live-serv and print an estimated cost first. Local .env uses SERV_MODE=fallback_only.
- 2026-11-14 D18: final-round rule R-FINAL-ACCEPT. bestAndFinal = floor + ceil(10% x (ask - floor)), capped at the ask; computed in code (engine.decide), applied before the model's action so a model reject cannot override it; accepts at the BUYER'S offer when offer >= bestAndFinal and offer > floor; final-round counters are set to bestAndFinal; one extra message after the last round may only take the standing ask (no SERV call, labeled fallback). The rule is added to every published policy (seed, owner publish, and a boot-time upgrade that publishes a new policy version for already-seeded shops). Verified by property tests and a SERV_MODE=fallback_only adversarial run (0 floor breaches, 0 leaks; Prompt Guard not exercised in that run).
- 2026-11-14 D19: Arena Send bug = button disabled until the catalog loaded (cold start). Fixed by queueing + retry (docs/evidence/arena-bug.md).
- 2026-11-14 D20: brand mark = uiref/brand2 files copied into apps/web/public; Kite and OpenServ logos remain only in the Built-on strip; the header Menu button is mobile/tablet only (<=900px) with a full-width sheet.
